采集器

把 agent 会话推送给 MyDays，是 Agent 工作汇总的素材来源。

  1. 和 MyDays 在同一台电脑在项目目录启动随附的采集器，令牌自动发放，无需配置：docker compose --profile agent-digest up -d
  2. 在其他电脑上在下方创建一个“采集”令牌，然后在那台电脑上运行（需要 Node.js 24）：MYDAYS_URL=http://MyDays地址:4173 MYDAYS_TOKEN=令牌 node collector/collector.mjs

让 agent 读取 MyDays

接入后可以直接问 agent “我上周做了什么”“帮我写本月周报”。只读，不能修改数据。

  1. 创建读取令牌在下方选择“读取”创建，把令牌保存到 ~/.mydays/mcp-read-token。
  2. Claude Codeclaude mcp add --scope user mydays -e MYDAYS_URL=http://localhost:4173 -e MYDAYS_TOKEN_FILE=$HOME/.mydays/mcp-read-token -- node MyDays项目目录/collector/mcp.mjs
  3. Codex在 ~/.codex/config.toml 的 [mcp_servers.mydays] 中配置同样的命令和环境变量。

快速记录

不打开页面也能记一笔：用 iOS 快捷指令、Raycast、Alfred 或脚本把待办和工作记录直接写进 MyDays。

  1. 创建快速记录令牌在下方选择“快速记录”创建。它只能添加待办和工作记录，不能读取或修改其他数据。
  2. 发送请求curl -X POST http://localhost:4173/api/agent/capture -H "Authorization: Bearer 你的令牌" -H "Content-Type: application/json" -d '{"type":"task","title":"给客户回电话","project":"工作"}'
  3. 可选字段type 为 task（默认）或 log；还可以带 project、priority（low / normal / high）、date 和 dueDate（YYYY-MM-DD）。不带 date 时记到今天。
  4. iOS 快捷指令添加“获取 URL 内容”动作，方法选 POST，填入上面的地址、两个请求头和 JSON 请求体，标题用“要求输入”的结果。
